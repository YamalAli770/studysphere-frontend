# Study Sphere 🎓

Study Sphere is a mentorship platform that connects students with experienced mentors to guide them through the study abroad journey.

## 🚀 Features

- 👥 Mentor–Student Matching  
  Connect with experienced mentors for personalized guidance  

- 💬 Real-Time Chat  
  Communicate seamlessly with mentors  

- 📹 Video Calling  
  Conduct one-on-one mentoring sessions  

- 💳 Payment Integration  
  Secure booking and payment for mentorship sessions  

- 📚 Centralized Resources  
  Access reliable information on admissions, visas, and scholarships  

## 🛠️ Tech Stack

- **Frontend:** Next.js, TypeScript  
- **Mobile:** React Native  
- **Backend:** Node.js (REST APIs)  
- **Database:** PostgreSQL (Neon DB)  
- **Version Control:** Git & GitHub  

## 🧠 Problem

Students planning to study abroad often struggle with:
- Scattered and unreliable information  
- Lack of personalized guidance  
- Limited access to experienced mentors  

## 💡 Solution

Study Sphere provides a centralized platform where:
- Students receive tailored mentorship  
- Mentors share real-world experiences  
- Information is accurate and up-to-date
